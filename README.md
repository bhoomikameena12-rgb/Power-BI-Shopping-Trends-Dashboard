# Power BI Shopping Trends Dashboard

## Project Overview
This project focuses on analyzing shopping trends and customer purchasing behavior using Microsoft Power BI. The dashboard presents business insights through interactive visualizations and filters.

## Objectives
- Analyze shopping and purchasing patterns.
- Explore customer behavior and product preferences.
- Present key business metrics through interactive dashboards.
- Support data-driven business decisions.

## Tools Used
- Microsoft Power BI
- Power Query (if used)
- DAX (if used)

## Dashboard Features
- Interactive visualizations.
- Key performance indicators (KPIs).
- Filters and slicers for data exploration.
- Shopping trend analysis.
- Customer purchasing behavior analysis.

## Key Insights
The dashboard helps explore shopping patterns, compare customer preferences, and identify trends that may support business decisions.

## Project Files
- Power BI dashboard (.pbix)

## How to Use
1. Download the `.pbix` file from this repository.
2. Open it using Microsoft Power BI Desktop.
3. Explore the dashboard and interact with the available filters.
